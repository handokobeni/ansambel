### Summary

Phase 2b melengkapi Work Mode dengan dua surface "berat" — xterm.js terminal dan
CodeMirror 6 editor — plus per-repo script runner yang stream output ke terminal
yang sama. Sebelum sub-phase ini, Work Mode read-only: user bisa melihat diff,
browse file tree, dan search, tapi tidak bisa membuka isi file (klik file di
FileBrowser hanya highlight row) atau menjalankan command apa pun. PR ini
menambah file-edit + save dengan sha1 race-detect, terminal interaktif yang
shell beneran, dan dropdown script yang stream live ke buffer xterm yang sama.
Tab strip tumbuh dari 3 ke 5 (Chat / Diff / Files / Editor / Terminal) dengan ⌃4
/ ⌃5 untuk Editor + Terminal — keduanya hidden-mount supaya CodeMirror undo
history dan xterm scrollback bertahan saat user pindah tab.

Plan doc dipisah backend/frontend di awal sub-phase:
`docs/superpowers/plans/2026-05-08-ansambel-phase-2b-{backend,frontend}.md`.

### Backend — empat surface baru

Empat module baru di `src-tauri/src/commands/`, masing-masing mengikuti pola
`_inner(...)` yang sudah established di Phase 1c (`agent_core`) supaya testable
tanpa runtime Tauri:

- **`scripts.rs`** (Task 1) — `script_list_inner`, `script_set_inner`,
  `script_run_inner`. RepoScript persisted di `repos.json` sebagai field baru di
  `RepoInfo`. `script_run` spawn PTY rooted di worktree dir, inherit broadcaster
  pattern dari `terminal.rs` (lihat di bawah) supaya output script muncul di
  buffer xterm yang sama dengan shell interaktif — tidak ada surface kedua untuk
  merge. `sha1 = "0.10"` ditambahkan ke `Cargo.toml` (dipakai juga oleh
  `file_io.rs` untuk race-detect).

- **`terminal.rs`** (Tasks 2+3) — lima command: `terminal_spawn`,
  `terminal_write`, `terminal_resize`, `terminal_kill`, `terminal_reattach`.
  Per-workspace `TerminalHandle` di `AppState.terminals` membungkus PTY
  session + `tokio::sync::broadcast::channel` (output bytes) + `Arc<AtomicBool>`
  (cancel signal). Reattach pattern mirror `agent` reattach dari Phase 1c: bila
  workspace switch lalu user kembali, channel baru di-subscribe ke broadcaster
  yang sama; broadcast lag (`RecvError::Lagged`) ditangani — buffer terlalu
  besar di-skip dan reader tetap hidup. Manual `Debug` impl di `PtySession`
  karena trait objects (`portable-pty`) tidak `derive(Debug)`-able.

- **`file_io.rs`** (Task 4) — `file_read_inner` dan `file_write_inner`. Read
  mengembalikan `{ content, is_binary, size, sha1 }` — binary detection lewat
  NUL-byte scan + non-UTF-8 fallback supaya editor tidak pernah render bytes
  acak. Write atomic via `.tmp` + rename (mirror `persistence/atomic.rs`) plus
  sha1 race-detect: kalau frontend kirim `expected_sha1` dan
  `sha1(disk_now) != expected`, return
  `AppError::InvalidState("FileChangedOnDisk: ...")` supaya editor bisa surface
  "reload before saving" toast tanpa silent overwrite. Path traversal defense
  via `resolve_within_worktree()` (di-promote ke `pub(crate)` dari `files.rs`
  yang Phase 2a tulis) — leading slash, drive letter, dan `..` semua di-reject
  sebelum I/O.

- **Registration** di `lib.rs` + `commands/mod.rs` — delapan command baru total.
  CI coverage exclusion regex di-extend ke `scripts|terminal|file_io` karena
  async Tauri wrapper di file-file ini memang tidak bisa di-cover lewat unit
  test (perlu runtime).

Total backend: 354 → 395 tests (+41), clippy `-D warnings` clean, fmt clean.

### Frontend — dua heavy components + satu picker + wiring

Tujuh module baru di frontend, plus modify `WorkspaceView` / `TabStrip` /
`App.svelte`. Dua dep baru di `package.json`:

- `@xterm/xterm` + `@xterm/addon-fit` (~150 KB minified)
- `codemirror` + 8 `@codemirror/lang-*` packages + `@codemirror/theme-one-dark`
  (~450 KB minified)

Total ~600 KB minified+gzipped — well within bundle budget per design spec.

- **`editor-tabs.svelte.ts`** (16 tests) — per-workspace
  `{ open: OpenFile[], active: string | null }`.
  `OpenFile = { path, content, diskSha1, isBinary, dirty }`. Methods: `openFile`
  (idempotent — re-activates kalau path sudah open), `setActive`,
  `updateContent` (compute dirty in-place), `markSaved` (clear dirty + update
  diskSha1), `closeFile` (pick neighbour as new active, null kalau list kosong),
  plus `forget` / `reset` untuk lifecycle + tests.

- **`lang.ts`** (13 tests) — pure helper `langForPath(path)` → `LangId | null`.
  Mapping ekstensi → CodeMirror language: ts/tsx/js/jsx/mjs/cjs → javascript, rs
  → rust, py → python, json → json, md → markdown, html/htm → html, css/scss →
  css, php → php. Unknown extension fall back ke null (no syntax highlighting,
  plain editor).

- **`Editor.svelte`** (10 tests) — CodeMirror 6 wrapper. EditorView dibuat
  sekali per workspace; ganti file pakai `view.dispatch({ changes: ... })` lewat
  `Compartment` untuk swap language extension tanpa remount. Konsekuensinya:
  undo history + scroll position + selection survive file switch. Suppress flag
  (`suppressUpdates`) supaya programmatic doc swap tidak loop balik ke
  `editorTabs.updateContent`. Ctrl+S → `api.file.write` dengan `expectedSha1`
  dari last read. `FileChangedOnDisk` rejection surface jadi explicit "reload
  before saving" toast — buffer tetap dirty supaya user yang putuskan. Empty
  state ("No file open") dan binary placeholder ("Binary file — preview not
  available.") di-render alih-alih editor body kalau `activeFile` null atau
  binary.

- **`Terminal.svelte`** (6 tests) — xterm.js wrapper. Dynamic import
  (`await import('@xterm/xterm')`) supaya cold-start splash + Plan mode tidak
  kena penalty 150 KB parse cost. `FitAddon` plus `ResizeObserver` pada
  container — sync xterm dimensions ke PTY via `terminal_resize` setiap kali tab
  unhide (display:none → block trigger ResizeObserver). `onData` callback encode
  keystrokes ke UTF-8 bytes via `TextEncoder` → `terminal_write`. Channel
  handler accept dua varian: `bytes` (write direct ke buffer xterm sebagai
  `Uint8Array` — preserve ANSI escapes) dan `exited` (render
  `[process exited with code N]` marker). Reattach-first, spawn-fallback supaya
  workspace switch + back tidak kill session. `unmounted` + `term?` guard untuk
  handle race antara dynamic-import resolution dan onDestroy.

- **`EditorTabBar.svelte`** (8 tests) — sub-tabs di Editor panel. One button per
  file, basename label, `•` dirty indicator, `✕` close button. Close pada file
  dirty `window.confirm` dulu — cancel keep file open. `aria-selected` per tab,
  `role="tablist"` + `role="tab"` untuk a11y. Click tab →
  `editorTabs.setActive`; click ✕ → `closeFile` (event propagation di-stop
  supaya tidak juga aktifkan tab).

- **`ScriptPicker.svelte`** (6 tests) — dropdown horizontal di header Terminal
  panel. `$effect` watch `repoId` → reload list; refetch on repoId change supaya
  pindah workspace ke repo lain swap list otomatis. Click script →
  `api.script.run` dengan fresh `Channel<TerminalChunk>`. Empty list render
  placeholder "No scripts configured."; load failure inline error; run failure
  jadi toast.

- **`TabStrip.svelte`** (8 tests) — extension dari 3 ke 5 tab, tambah
  `tab-editor` + `tab-terminal` dengan kbd hint `⌃4` / `⌃5`. Active state
  - tabindex rotation tetap bekerja untuk semua 5.

- **`WorkspaceView.svelte`** (39 tests) — wiring level: FileBrowser `onOpen`
  callback sekarang bukan no-op. Click file → `api.file.read` →
  `editorTabs.openFile` → `workspaceTabs.setActive('editor')`. Editor
  - Terminal panel di-mount permanently (hidden via `class:hidden`) supaya
    CodeMirror undo + xterm scrollback survive tab switches sesuai hard rule.
    Failure path file_read surface toast tanpa switch tab — user tetap di Files
    supaya bisa coba file lain.

- **`App.svelte`** — register `ctrl+4` / `ctrl+5` shortcut yang switch active
  tab ke editor / terminal saat workspace selected. SearchModal jump handler
  tetap route ke Files tab + highlightedFile (consistent dengan Phase 2a UX);
  user klik row di FileBrowser untuk benar-benar buka file di Editor.

Total frontend: 517 → 592 tests (+75), eslint + prettier clean, `bun run check`

### Architecture decisions

- **Hidden-mount Editor + Terminal** — bukan unmount-on-tab-switch. CodeMirror
  undo history dan xterm scrollback adalah resource yang precious; remount akan
  membuangnya tanpa benefit. ResizeObserver di Terminal handle layout-flip dari
  display:none → block.
- **Compartment pattern di CodeMirror** — alih-alih recreate `EditorView` per
  file, dispatch `Compartment.reconfigure` untuk swap language extension. Doc
  state swap via `view.dispatch({ changes: ... })`. Trade-off: satu `EditorView`
  per workspace shares undo stack across files (CM6 default), yang behaviour-nya
  match VS Code per-file undo via `setState`. Phase 2c kalau perlu per-file
  undo, swap ke `view.setState(EditorState.create(...))`.
- **Bytes via JSON number array, bukan binary Tauri Channel** —
  `Channel<TerminalChunk>` carry `bytes: number[]` walaupun JSON serialize cost
  setiap chunk. Reason: konsistensi dengan AgentEvent pattern yang sudah
  established di Phase 1c. Backend convert `Vec<u8>` → JSON array satu kali;
  frontend buat `Uint8Array(chunk.bytes)` di handler. Di practice xterm chunk
  size ~ 4-16 KB jadi JSON overhead tidak material.
- **sha1 race-detect, bukan mtime** — agent dan user bisa edit file bersamaan.
  mtime resolution OS-dependent (Windows FAT 2-detik) dan unreliable across
  copy-on-write FS. sha1 deterministic dan murah untuk file < 1 MB (editor
  refuse buka file di atas itu via binary detection fallback).
- **Atomic write `.tmp + rename`** — mirror `persistence/atomic.rs`. Process
  kill mid-write tidak meninggalkan file kosong / corrupt.
- **PTY broadcaster di backend** — satu reader thread per workspace populate
  `tokio::sync::broadcast::channel`; channel handler frontend subscribe lewat
  reattach. Lag handled (`RecvError::Lagged`) tanpa kill reader. Sama pattern
  dengan agent broadcaster di Phase 1c.

### Lessons / catatan

- **CodeMirror 6 + Svelte 5 reactivity** — CM owns DOM and reactivity
  internally; Svelte effect-loop trap kena di Phase 2a (FileBrowser) bisa kambuh
  kalau `$effect` tracking `editorTabs.activeFile` lalu `dispatch` ke CM yang
  trigger update listener yang call `editorTabs.updateContent`. Solusi:
  `untrack(...)` body $effect + `suppressUpdates` flag yang set-true sebelum
  programmatic dispatch.
- **xterm.js dynamic import + race condition** — `await import('@xterm/xterm')`
  bisa resolve setelah component already destroyed (test mounting + destroying
  cepat). Tanpa `if (unmounted || !term) return` setelah `await tick()`, akses
  `term.onData` crash karena onDestroy sudah set `term = undefined`. Pattern:
  setiap `await` di onMount harus diikuti guard kalau code setelahnya touch
  state yang bisa di-null oleh onDestroy.
- **`ScriptPicker` mock-friendly defaults** — kalau `api.script.list` return
  undefined (test mock yang lupa handle command), `scripts.length` crash.
  Defensive default `Array.isArray(list) ? list : []` di store consumer side
  bukan signed-off pattern but useful as a soft barrier untuk integration tests
  yang tidak granular configure setiap mock.
- **Test mock isolation across components** — WorkspaceView test sekarang mount
  Terminal yang depend pada `@xterm/xterm` + `ResizeObserver`. jsdom tidak punya
  ResizeObserver dan canvas measurement APIs, jadi mock-mock yang sama di
  Terminal.test.ts harus di-replicate di WorkspaceView.test.ts (vi.mock di
  module top-level). Pattern: kalau component A mount component B yang punya
  heavy ESM dep, A's tests butuh same mocks as B's tests.
- **PR scope decision: SearchModal jump ke editor di-defer** — ada temptation
  untuk wire search-jump → open-file-in-editor (sesuai plan Task 8 sub-bullet
  "Search jump with a line number additionally calls view.dispatch..."). Tapi
  itu break Phase 2a E2E test yang assert jump → Files tab. Keep behaviour Phase
  2a sebagai highlight-only; user klik row untuk benar-benar buka di editor.
  Line-jump butuh signal channel ke Editor.svelte dan editor-tabs store API baru
  (`requestJump`) — ditunda ke polish PR berikutnya.
