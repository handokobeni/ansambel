### Summary

Phase 2a fills out the Work Mode surface area. Sebelum PR ini, membuka workspace
hanya menampilkan ChatPanel — tidak ada cara untuk melihat perubahan kode,
menelusuri file di worktree, atau melompat ke file via search. PR ini menambah
tiga read-only surface baru di balik tab strip baru di `WorkspaceView`, plus
satu modal Ctrl+P / Ctrl+Shift+F global, sambil tetap menjaga ChatPanel hidup di
DOM dengan pola hidden-mount supaya scroll position dan state-nya bertahan saat
user pindah tab.

Ada dua plan doc yang ditulis di awal sub-phase (mengikuti cadence Phase 1):
`docs/superpowers/plans/2026-05-07-ansambel-phase-2a-{backend,frontend}.md`.

### Backend — tiga command baru, semua streaming/lazy

Tiga `#[tauri::command]` baru, masing-masing pakai pola
`_inner(workspace_id, state, emit)` agar testable tanpa runtime Tauri (sama
dengan agent_core di Phase 1):

- **`workspace_diff`** (`src-tauri/src/commands/diff.rs`, 6 unit tests +
  registration) — `git diff --no-color HEAD` dengan fallback ke empty-tree OID
  (`4b825dc6…`) untuk repo tanpa commit. File untracked disintesis sendiri jadi
  blok unified-diff (header `--- /dev/null` + `+++ b/<rel>` + setiap baris jadi
  `+<line>`) karena `git diff` skip untracked secara default. File yang
  ukurannya di atas 1 MB atau yang mengandung NUL byte muncul sebagai
  `Binary file <path> not shown` — matches behaviour `git diff` untuk binary
  content. Output di-chunk ke ≤ 64 KB sebelum dikirim via `Channel<DiffChunk>`
  (`text` / `error` / `eof`). Boundary char-aware supaya tidak memotong UTF-8
  multi-byte di tengah.

- **`workspace_files`** (`src-tauri/src/commands/files.rs`, 9 unit tests +
  registration) — listing direktori imediate (depth 1) via `ignore::WalkBuilder`
  dengan `standard_filters(true)` untuk menghormati `.gitignore`. Path traversal
  ditolak via `dunce::canonicalize` + prefix check sebelum walk. Crate baru:
  `ignore = "0.4"` (yang juga dipakai oleh ripgrep di balik layar). Ordering
  directories-first → alphabetical case-insensitive supaya konsisten dengan
  konvensi file-explorer.

- **`workspace_search`** (`src-tauri/src/commands/search.rs`, 9 unit tests +
  registration) — dua mode dalam satu command:
  - filename: `ignore::Walk` + case-insensitive substring, gitignore-aware, cap
    500 hits.
  - content: shell-out ke `rg --json --max-count 100 --max-filesize 1M`, parse
    line-by-line JSON. Kalau `rg` tidak ada di PATH, emit satu sentinel
    `RipgrepUnavailable { reason }` lalu `Eof` — frontend pakai sinyal itu untuk
    menampilkan CTA "install ripgrep" tanpa silently degrade. Setiap path sukses
    berakhir dengan `SearchHit::Eof` supaya consumer release loading
    spinner-nya.

Streaming command (diff + search) jalan di `tokio::task::spawn_blocking` karena
`git`/`rg` shell-out + file I/O bersifat sync; channel `send` dilakukan dari
blocking pool tanpa block runtime. Cancellation otomatis: kalau user pindah
workspace, channel di-drop di frontend, backend `tx.send` error → loop keluar.

Total backend: 333 → 354 tests (+21), clippy `-D warnings` clean, fmt clean.

### Frontend — tab system + tiga komponen + satu modal

Plus satu store baru, satu helper murni, dan integrasi di `App.svelte` /
`WorkspaceView.svelte`. Tidak ada dep baru — `highlight.js` sudah ada dari Phase
1 (markdown work) dan parser unified-diff cukup kecil untuk in-tree.

- **`workspace-tabs.svelte.ts`** (8 tests) — per-workspace `{active, expanded}`.
  Penting: storage di-split jadi `SvelteMap<string, WorkspaceTabId>` untuk
  active tab + plain `Map<string, SvelteSet<string>>` untuk expanded paths.
  Outer Map sengaja **tidak** SvelteMap karena `expanded()` lazy-create entry
  pada read pertama; kalau outer Map ikut reactive, mutation-on-read di dalam
  `$derived` (tepatnya yang FileBrowser lakukan setiap render) memicu
  `effect_update_depth_exceeded`. Inner SvelteSet sudah cukup reactive untuk
  semua yang UI butuhkan (`has` / `add` / `delete`).

- **`TabStrip.svelte`** (6 tests) — pure UI, tiga tab Chat / Diff / Files,
  proper `role="tablist"` + `aria-selected` + `tabindex` rotation, kbd hint
  `⌃1`/`⌃2`/`⌃3` per tab. Keyboard shortcut ditangani di App-level
  `ShortcutRegistry` supaya konsisten dengan rest of app.

- **`DiffView.svelte`** (8 tests) + **`parseUnifiedDiff`** (`src/lib/diff.ts`, 9
  tests) — komponen mount → buat `Channel<DiffChunk>` → buffer semua `text`
  chunks → parse sekali pas `eof`. Per-chunk parsing dihindari karena hunk
  header bisa terbelah antar chunk batas 64 KB. Render green/red row tagging +
  sticky file header + Refresh button + error banner. Generation id (counter)
  dipakai untuk drop chunk dari stale request kalau user klik Refresh sebelum
  stream sebelumnya selesai.

- **`FileBrowser.svelte`** (10 tests) — lazy tree dengan ▸/▾ chevron, click
  directory toggles expanded set di store, click file fires `onOpen(path)`
  callback. Children dicache per parent path supaya re-expand tidak memicu fetch
  ulang. Per-directory error state (untuk path yang gagal dimuat) dirender
  inline — satu direktori unreadable tidak menjatuhkan seluruh tree. Wrap
  `$effect` body di `untrack()` karena `loadChildren()` baca-tulis `loading` map
  (read sebagai guard, write sebagai state) — tanpa untrack dependency
  self-cycle memicu update-depth error.

- **`SearchModal.svelte`** (12 tests) — modal global (Ctrl+P filename,
  Ctrl+Shift+F content), focus trap ke input, Escape close, search-on-Enter
  (bukan as-you-type — keep cancel surface kecil di 2a; debounced live search
  bisa nyusul polish). Streamed hits ke `<ul role="listbox">`. Click hit → tutup
  modal + `onJump(path, line?)`. Banner "ripgrep unavailable" muncul kalau
  backend emit sentinel-nya.

- **`WorkspaceView.svelte`** — wrap ChatPanel + DiffView + FileBrowser di tiga
  `<div role="tabpanel">` yang flip `display:none/block` lewat `class:hidden`.
  ChatPanel sendiri **selalu** mounted supaya scroll position bertahan. DiffView
  dan FileBrowser juga always-mounted — `$effect` mereka re-load data saat
  `workspaceId` berubah, tapi state UI (refresh count, expanded paths) bertahan
  antara tab switch. 4 test baru di `WorkspaceView.test.ts` membuktikan: tab
  strip render alongside header, default tab adalah chat, klik diff/files toggle
  visibility, dan ChatPanel tetap di DOM (cuma `class:hidden`) saat tab lain
  aktif.

- **`App.svelte`** — mount `<SearchModal />` di app shell + register dua
  shortcut baru. `highlightedFile` di-state di sini (App level, bukan
  WorkspaceView) supaya `onJump` modal bisa stamp path ke FileBrowser lewat prop
  drilling. Click hit → `workspaceTabs.setActive('files')` +
  `highlightedFile = path`. Editor + line jump menyusul di Phase 2b.

Total frontend: 433 → 517 tests (+84), eslint + prettier clean, `bun run check`
(svelte-check + tsc) clean.

### Architecture decisions yang di-locked di plan + tetap dipegang

- **`git diff` shell-out, bukan libgit2** — sesuai pola `detect_default_branch`
  yang sudah ada.
- **Ripgrep optional dengan sentinel fallback, bukan crate** — sama pattern
  dengan `gh` dan `claude` binary detection.
- **Tab system di `WorkspaceView`, bukan window-level** — per-workspace state
  isolation lewat `workspace-tabs` store.
- **Hidden-mount per tab** — bukan unmount-on-switch, supaya ChatPanel scroll
  position dan future xterm/CodeMirror buffer bertahan tanpa custom logic.
- **Search sebagai modal global, bukan tab tersendiri** — modal lebih matching
  dengan VS Code Ctrl+P UX dan tidak perlu real-estate permanent. Klik hit →
  switch ke Files tab.

### Lessons / catatan

- Svelte 5 `effect_update_depth_exceeded` muncul dua kali selama development:
  sekali di `workspaceTabs.expanded()` (write-on-read di SvelteMap) dan sekali
  di FileBrowser (`$effect` baca + tulis ke `loading` map). Pelajaran: kalau
  outer container di-create lazy-on-read dan dipakai oleh banyak `$derived`,
  jangan SvelteMap-kan; cukup reactive di level inner. Atau bungkus body $effect
  dengan `untrack()`.
- TypeScript flow analysis berhenti narrow `let current: DiffFile | null` di
  iterasi loop walaupun closure (startFile) sudah me-reassign. Solusi paling
  bersih: re-bind ke `const file: DiffFile = current` setelah null-check, lalu
  pakai `file` di sisanya.
- Path-comparison untuk worktree containment harus pakai `dunce::canonicalize`
  (bukan plain `canonicalize`) supaya kompatibel dengan Windows verbatim path
  prefix. Pelanggaran ini tidak akan ketahuan di Linux runner sampai PR di-test
  di Windows CI.
